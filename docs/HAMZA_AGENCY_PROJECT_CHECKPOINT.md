# HAMZA AGENCY — Project Checkpoint Reference

هذا الملف مرجع رسمي داخل GitHub لحالة مشروع HAMZA AGENCY.
الغرض منه منع تكرار تنفيذ نفس الخطوات في هذه المحادثة أو أي محادثة لاحقة.

## قاعدة العمل المعتمدة

قبل اقتراح أو تنفيذ أي خطوة جديدة، يجب مراجعة هذا الملف والتأكد أن الخطوة ليست ضمن المنجزات المعتمدة.
أي بند ضمن قائمة المنجزات يعتبر مغلقاً ولا يعاد تنفيذه إلا بطلب صريح من صاحب المشروع.

---

## المؤجلات الرسمية

1. إنشاء بريد رسمي للدومين.
   - مؤجل بطلب صاحب المشروع.
   - أمثلة: info@hamza-agency.com أو support@hamza-agency.com.
   - يتم من مزود الدومين أو خدمة بريد خارج الكود.

2. الفحص البصري النهائي من جهاز صاحب المشروع بعد آخر نشر ناجح على Vercel.
   - الصفحة الرئيسية، البرامج، تفاصيل البرامج، الانضمام، طلب الخدمة، التتبع، الوظائف، الفوتر، الجوال، سطح المكتب، لوحة الإدارة، النسخة الاحتياطية.
   - آخر نشر على Vercel تم التحقق من نجاحه عبر GitHub status.
   - المتبقي هنا ليس كوداً جديداً، بل تأكيد بصري/يدوي من المتصفح بعد النشر.

3. مراقبة Google Search Console بعد الفهرسة.
   - sitemap نجح واكتشف الصفحات.
   - المطلوب لاحقاً مراقبة الفهرسة فقط من حساب Google Search Console.

4. إضافة روابط السوشيال الرسمية عند توفرها.
   - لا يتم إضافة روابط غير رسمية أو تجريبية.
   - لم يتم اعتماد أي روابط سوشيال حتى الآن لأن صاحب المشروع لم يزوّد روابط رسمية مؤكدة.
