# HAMZA AGENCY — V1 Launch Checkpoint

هذا الملف هو نقطة تثبيت رسمية لنسخة الإطلاق V1 حتى لا نعيد تنفيذ خطوات منجزة أو نرجع المشروع لنقطة الصفر.

## قرار V1 الرسمي

نسخة V1 تعتبر نسخة إطلاق عندما تكون الشروط الأساسية التالية مغلقة:

- Build ناجح.
- Git نظيف بعد الرفع.
- الدومين مربوط سابقاً ولا يعاد ربطه من جديد.
- الصفحات العامة الأساسية موجودة.
- لوحة الإدارة الأساسية موجودة.
- اتصال Supabase مفحوص بالمفاتيح العامة فقط.
- أي مفتاح سري تم كشفه يتم تدويره أو حذفه من Supabase.

أي تحسين غير ضروري للإطلاق ينتقل إلى V2 ولا يمنع إطلاق V1.

## منجز ومثبت

- تم تشغيل Build بنجاح من Codespaces.
- تم إنشاء وتثبيت package-lock.json.
- تم تحديث tsconfig.json نتيجة build/npm بشكل طبيعي.
- تم رفع التحديثات إلى GitHub.
- تم التأكد أن git status نظيف بعد الرفع.
- الدومين مربوط سابقاً، والمتبقي فقط فحص نهائي بعد آخر Deploy.
- صفحة /admin/launch-checklist موجودة فعلاً وتستخدم لفحص روابط الإطلاق.
- صفحة /admin/applications موجودة فعلاً وليست مهمة إنشاء من الصفر.
- نظام الصلاحيات يقرأ admin_permissions من lib/adminAccess.ts.

## إجراءات يدوية لا أستطيع تنفيذها من GitHub

### 1. تدوير أو حذف المفتاح السري المكشوف

أي مفتاح سري خاص بـ Supabase تمت مشاركته يجب تدويره أو حذفه من Supabase قبل أي متابعة على قاعدة البيانات.

لا يوضع المفتاح السري داخل متغيرات عامة للواجهة، ولا يرسل لأي شخص.

### 2. تجهيز env محلي فقط في Codespaces

يجب وضع القيم العامة فقط داخل الملف المحلي `.env.local` في Codespaces:

```env
NEXT_PUBLIC_SUPABASE_URL=https://PROJECT_ID.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=PUBLIC_PUBLISHABLE_KEY
```

ملاحظات:

- لا تستخدم رابط ينتهي بمسار REST.
- لا تستخدم أي مفتاح سري.
- لا ترفع `.env.local` إلى GitHub.

### 3. فحص جداول Supabase

بعد تجهيز `.env.local` محلياً، يتم فحص الجداول الأساسية فقط. إذا ظهر نقص جدول واحد أو جدولين، يتم إصلاحهما فقط. لا نفتح تحسينات جديدة ضمن V1.

## بنود V2 المؤجلة ولا تمنع الإطلاق

- التحسينات الجمالية المتقدمة والحركات.
- كروت/مربعات متحركة إضافية للخدمات والإحصائيات والخلفيات.
- Excel متقدم.
- Analytics متقدم.
- Trash/Restore متقدم.
- Version History.
- Media Library متقدمة.
- Multi-language panel كامل.
- Auto Backups مجدولة.
- White-label readiness.
- AI Support / Knowledge Base أعمق.

## قاعدة العمل بعد هذا الملف

لا نضيف قائمة متبقيات جديدة إلا إذا تحقق أحد الشرطين:

1. ثبت من الكود أو الفحص أنها مشكلة تمنع الإطلاق.
2. طلب صاحب المشروع إضافتها صراحة.

غير ذلك يعتبر تحسين V2 وليس جزءاً من إغلاق V1.
