# HAMZA AGENCY — Full Completion Execution Plan

هذا الملف خطة تنفيذ عملية لإنهاء مشروع HAMZA AGENCY بالكامل، وليس فقط نسخة الإطلاق الأولى.

المرجع الأعلى دائماً هو:

`docs/HAMZA_AGENCY_PROJECT_CHECKPOINT.md`

---

## قواعد التنفيذ

1. لا يتم إعادة فتح أي بند موجود ضمن المنجزات الرسمية في ملف Checkpoint.
2. أي خطوة توسعية تنفذ وحدها، ثم يتم فحص النشر قبل الخطوة التالية.
3. إذا فشل Vercel بعد تعديل، يتم إصلاح الفشل أو التراجع عن التعديل قبل متابعة أي ميزة جديدة.
4. لا يتم حذف صفحات أو ميزات عامة قائمة.
5. لا يتم تغيير بنية قاعدة البيانات عشوائياً من الكود بدون قرار واضح.
6. كل توسعة يجب أن تحفظ قابلية العمل على الجوال وسطح المكتب.

## ترتيب التنفيذ المقترح

### المرحلة 1 — تثبيت الأساس وعدم كسر النشر

1. التأكد من نجاح آخر نشر Vercel بعد كل commit.
2. عدم تنفيذ أي تعديل حساس إذا كان آخر نشر فاشلاً.
3. إصلاح أي build failure قبل متابعة التوسعات.

### المرحلة 2 — تحسينات إدارية صغيرة وآمنة

1. تحسين عرض Activity Logs ليدعم أسماء الأعمدة الموجودة فعلياً.
2. توسيع Activity Logs تدريجياً لكل صفحة إدارة، صفحة بصفحة.
3. توثيق كل نقطة يتم إغلاقها في Checkpoint.

### المرحلة 3 — Knowledge Base والدعم الذكي

1. تثبيت عرض قاعدة المعرفة الحالي.
2. إضافة إدارة قاعدة المعرفة بشكل آمن بعد معرفة بنية جدول `knowledge_base` بدقة.
3. ربط العناصر المنشورة بالدعم الذكي.
4. تسجيل الأسئلة غير المجابة.
5. تحسين صفحة /admin/ai-support لإدارة المتابعة.

### المرحلة 4 — التتبع والخصوصية

1. إضافة كود تتبع مستقل لطلبات الانضمام.
2. تعديل صفحة التتبع لتدعم الكود.
3. إبقاء رقم واتساب المستخدم مخفياً في نتائج التتبع.
4. ربط الكود بلوحة الإدارة.

### المرحلة 5 — التصدير والنسخ والـ Trash

1. توسيع Export Center ليصبح مركز تصدير فعلي.
2. توسيع Backup System ليشمل معلومات أوضح وسجلات أقوى.
3. توسيع Trash System تدريجياً لكل الحذوفات.

### المرحلة 6 — White Label والإعدادات

1. نقل الهوية العامة إلى Settings CMS.
2. جعل الاسم والشعار والألوان والواتساب والبريد والسوشيال قابلة للتعديل.
3. تجهيز Demo / Template للبيع.
4. توثيق طريقة تركيب نسخة وكالة جديدة.

### المرحلة 7 — الترجمة والـ SEO المتقدم

1. تحويل اللغة من واجهة فقط إلى محتوى مترجم فعلي.
2. دعم العربية والإنجليزية والتركية.
3. إضافة SEO لكل لغة.
4. إضافة Structured Data متقدم.

### المرحلة 8 — الفحص والتسليم

1. Public Text Audit.
2. Visual / Responsive Final QA.
3. فحص الدعم الذكي.
4. فحص الإدارة.
5. فحص Search Console.
6. إعداد دليل التشغيل والتسليم.
